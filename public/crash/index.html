Why does the PC keep switching off?

Record the PC while you play, drop the recording here, and the Crisp-o-Meter rates how cooked it got, from Brined to Gluttened. If it crashed, you get a line-up of the most likely suspects with the evidence for each, and what to test next.

  1. Get the kit. Unzip it somewhere easy, like Documents. Download the kit (.zip) Read the script first →
  2. Start cooking. Double-click 1-START-COOKING. Leave the black window open; you can minimise it.
  3. Play until it dies. The game, Photoshop, whatever usually does it. If the PC switches off, turn it back on.
  4. Plate it. Double-click 2-PLATE-IT, then drop the KGFFC-plate file from your Desktop below.

Extra Crispy mode: Windows can't see CPU temperature or voltages on its own. Turn on HWiNFO logging too (the README shows how) and the plate picks it up automatically.

            How a crash detective works

            1. Brine first. Record ten boring minutes on the desktop. That's what "normal" looks like on this PC.
            2. Catch it in the act. Record while doing the thing that kills it. A crash we didn't record is only a rumour.
            3. Start with suspect #1. Change ONE thing from its "What to try" list. Write down what you changed and the date.
            4. Record again. Same game, same length. If it stops crashing for a week, you found it. If not, undo the change and try the next suspect.
            5. Grown-ups do the insides. Anything inside the case is switched off at the wall first. Never open a power supply: it can hurt you even when unplugged.

            The Crisp-o-Meter rates the recording, not the PC's soul. The suspect list is a ranking of evidence, not a diagnosis: it tells you what to test first. Privacy: the kit never records user names, PC names, IP addresses or serial numbers, and this page makes no network requests with your data (its security policy blocks them outright).
